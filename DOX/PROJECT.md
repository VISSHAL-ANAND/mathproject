# Project Overview
Title: Response Time Prediction Using Regression Models.

Problem: estimate elapsed minutes between support-request submission and first response.

Scope: data validation, regression model comparison, metrics, visualizations, interactive prediction, and mathematical explanation.

Out of scope: predicting resolution time, SLA guarantees, and production ticket-system integration.

Success means the app runs, validates input, fits preprocessing only on training data, evaluates held-out data, predicts an estimate, and explains limitations.
